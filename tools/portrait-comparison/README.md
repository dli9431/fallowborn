# Portrait v2 comparison fixture

Open `index.html` directly from `file://`. The page renders the read-only Court
Illustration reference beside the shipping renderer for a fixed matrix of culture,
faith, age, sex, condition, headwear, and equipment cases. It is developer tooling and
is not loaded by the game or included by the browser test harness.

The fixture deliberately makes no automated pixel-similarity claim. Use it to review
identity, landmark placement, silhouette, framing, wardrobe semantics, visible health,
and equipment, then use the Playwright semantic tests for deterministic behavior.
