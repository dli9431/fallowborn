# Localization pipeline state

This directory holds tracked development data for `tools/i18n_catalog.py`. It is not loaded by
the browser game.

- `i18n-cache/<locale>.json` maps stable source-text hashes to translated leaf strings. The
  `translate` command reuses the cache so unchanged prose is not translated again.
- `i18n-coverage.json` and `i18n-coverage.md` are generated by the `extract` command.
- `translate*.log` records historical translation progress and is not consumed by the tool.

The cache and reports contain catalog prose, hashes, counts, and progress messages only. They do
not contain API keys, request headers, cookies, passwords, or other credentials. If the
translation backend later requires authentication, keep credentials outside this directory and
outside Git.
